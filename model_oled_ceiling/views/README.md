# 9 塊 OLED 定稿配置的多角度圖

用 f439095d 的 `../fire_model_oled_through_hole.blend` 渲染（Cycles）。只出圖，模型沒有改。

- `render_views.py`：人眼視角 3 張、等角斜視剖切 1 張、側視 4 張。
- `render_panorama.py`：拉遠全景 1 張。

圖中的配色與說明：
- **OLED**：顯示區用亮青色，旁邊的黃色字是路口名稱（NW、NE、SE、SW 角落，CENTER／C 中心，N、E、S、W 十字臂）。
- **人偶**：只是示意，用 40 mm 高的圓柱加球表示；模型裡本來沒有人偶物件。
- **閘門塊**：用改矮後 94 mm 的網格，各放一個在 N 環廊東段（G36）和東臂（G42）。
