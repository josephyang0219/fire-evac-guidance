## 2. Colab：訓練

```python
!python train.py --device 0 --workers 2 --batch-size 32 \
  --data /content/fire7/data.yaml --img 576 576 \
  --cfg cfg/fire7/yolov7-tiny-fire7.yaml --hyp cfg/fire7/hyp.ft7.yaml \
  --weights {D}/best.pt --epochs 60 --name fire7 --cache-images
!cp -r runs/train/fire7 {D}/
```

- `--weights best.pt`：從 6 類模型接續。nc 從 6 變 7，偵測頭的形狀不同，yolov7 會自動只載入形狀相同的層（log 會顯示 `Transferred xxx/yyy items`），backbone 保留、偵測頭重新學。
- `--img 576 576`：訓練用正方形，上板時是 576×320，yolov7 推論時會 letterbox，兩者相容（576、320 都是 32 的倍數）。
- `hyp.ft7.yaml`：由 `hyp.ft.yaml` 複製，只改 lr0 0.006、warmup 2、hsv_v 0.5、mixup 0.1（檔案裡有註解）。

## 3. Colab：重參數化

```python
!python reparam.py --weights runs/train/fire7/weights/best.pt \
  --cfg cfg/fire7/yolov7-tiny-fire7-deploy.yaml --out best_reparam.pt
!cd /content && zip -j best_reparam_pt.zip /content/yolov7/best_reparam.pt && cp best_reparam_pt.zip {D}/
```

`reparam.py` 做的事：

1. 讀訓練版權重（最後一層 `IDetect`，有 `ImplicitA`/`ImplicitM` 兩組隱式參數）。
2. 用部署版 yaml（最後一層 `Detect`）建同樣的網路，複製所有形狀相同的權重。
3. IDetect 每層是 `y = im·(W·(x+ia)+b)`，展開成一般卷積：`W' = im·W`、`b' = im·(b + Σ W·ia)`，寫進 Detect。
4. 用 1×3×320×576 的隨機輸入比對兩個模型，最大差異 < 1e-3 才存成 half 精度的 `best_reparam.pt`。

建議再用部署版跑一次 `test.py`（`--weights best_reparam.pt`），mAP 應和訓練版一樣（舊模型兩者都是 0.782）。

## 4. Realtek 線上轉檔（amebaiot.com → AI Model Conversion）

| 欄位 | 填寫 |
|---|---|
| 模型類型 | **YOLOv7-TINY-Pytorch** |
| 上傳模型 | `best_reparam_pt.zip`（內含 `best_reparam.pt`；上限約 35 MB，tiny 約 12 MB） |
| 輸入尺寸 | **576 × 320**（寬 576、高 320，要和韌體 NNW/NNH 一致） |
| 量化 | **UINT8** |
| 類別數 | **7** |
| 量化校正圖 | `fire7_quant_images.zip`（30 張 576×320，從 val 各來源平均挑出） |

**校正圖不要再用舊的 `quant_images.zip`**：那是 10 張很暗的渲染圖，UINT8 量化的數值範圍會照暗圖估計，實景偏亮時容易飽和。新的校正圖混了渲染、教室照片，實拍照片進資料集後也會被挑進去。
