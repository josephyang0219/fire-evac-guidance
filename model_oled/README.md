# 麵包板座外端面 OLED 面板（fire_model.blend 補件）

依 `實體模型檔案/fire_model.blend` 量測後設計。**原檔沒有修改**；每種 OLED 各另存一份「原模型＋新增 `OLED_*` 集合」的 .blend。

支援兩種 OLED（HUB-8735 SDK 內建的 `Wire/examples/OLED_SSD1306` 支援 128×64 與 128×32，兩者都是 SSD1306）：

| 資料夾 | OLED | 面板厚 | 模組固定 |
|---|---|---|---|
| `oled_096/` | **0.96 吋 128×64（方向指引建議用這個）** | 6.0 mm | 4 支 M2×4 自攻 |
| `oled_091/` | 0.91 吋 128×32 | 5.2 mm | 無安裝孔 → 凹槽定位＋背面點膠 |

每個資料夾內：`fire_model_oled_*.blend`（8 座共 32 件）、`OLED面板_*_x8.stl`（8 片共用）、`干涉與視野檢查.txt`、3 張檢查圖。

重跑（輸出路徑請用英文，Blender 收不到中文參數）：
```bash
blender -b <fire_model.blend 的複本> --python add_oled_panels.py -- 0.96 oled_096/fire_model_oled_096.blend oled_096
```

## 方向指引用哪一種

| | 0.96 吋 128×64 | 0.91 吋 128×32 |
|---|---|---|
| 顯示區 | 21.7 × **10.9** mm | 22.4 × **5.6** mm |
| 箭頭最大高度 | 約 10 mm（64 px） | 約 5.5 mm（32 px） |
| 一個畫面能放 | 大箭頭＋出口文字＋狀態列 | 小箭頭＋一行字，或輪流顯示 |
| 固定 | 四角 M2 孔，可鎖 | 通常無孔，只能膠合 |

→ **0.96 吋**當方向號誌；0.91 吋適合當輔助文字條（例如「擁擠」、人數）。

## 為什麼這樣設計（量測結果）

- 麵包板座外端面 59×37.5 mm（y = 144.5、z = 109～146.5），在樓層盒外側突出約 22 mm。
- **原端牆是楔形**：外面平、內面斜，頂部尖端只到 z ≈ 130.2，再往上只剩兩側 1.5 mm 薄牆，中間是開口。
- 傾斜 18° 的麵包板下緣頂在楔形內面 → 端面後方的下半部沒有空間。
- 第 1 版把模組放在端牆後面，玻璃會和楔形尖端重疊 0.2 mm；**改成把模組包在面板裡**，完全不必配合楔形。
- 排針一律朝內，且杜邦母座最低點要高於楔形尖端，才能直接伸進座內開口：
  - 0.96 吋：排針在上緣，模組放在 z 113～141，母座最低 z 137.8
  - 0.91 吋：排針在短邊直向排列，模組放在 z 130.3～142.3，母座最低 z 131.2

## 結構

```
 外 ←──────────── 面板厚 ────────────→ 內（原端面 y = 144.5）
 │ 前牆 1.5（開窗） │ 玻璃 │ PCB │ 背面零件 │ ← 貼著原端面
```

- 面板與端面同大小；外觀只多突出 5～6 mm。
- 開窗比顯示區每邊大 1.2 mm，顯示區中心放在面板左右中央。
- 面板以 2 支 **M2 沉頭自攻螺絲**鎖進楔形下段（z = 113，該處厚約 5.6 mm），可再點膠。

## 自動檢查結果（兩種都通過）

- 新零件與既有零件：**無互穿**（面板、模組背面與原端面只是貼合）
- 杜邦母座高於楔形尖端；模組背面到麵包板 ≥ 4.4 mm
- 8 台鏡頭都看不到任何一塊 OLED（在樓層盒外、天花板上方）
- 面板網格封閉（非流形邊 0）；前牆在窗口以外完全遮住模組；模組不會從窗口掉出

## 列印與組裝

1. 列印：**前面朝下**平放（窗口與沉頭在底面，凹槽朝上）→ 不需支撐。8 片＋備品。
2. OLED 模組正面朝前牆放進凹槽：0.96 吋從背面鎖 4 支 M2×4；0.91 吋在 PCB 背面四角點膠。
3. 杜邦線接好（GND、VCC、SCL→Pin 4、SDA→Pin 3）後，把面板貼上端面，鎖 2 支 M2。

## ⚠️ 列印前必須用實物確認

尺寸是網路上常見模組的標稱值，各廠會差 0.5～1 mm；不同就改 `add_oled_panels.py` 的 `VARIANTS` 重跑：

| 項目 | 0.96 吋 | 0.91 吋 |
|---|---|---|
| PCB | 27.3 × 27.8 × 1.6 | 38.0 × 12.0 × 1.2（也有 35.8 或 36 × 12.5） |
| 玻璃 | 26.7 × 19.3 × 1.4，下緣距 PCB 下緣 1.0 | 30.0 × 11.5 × 1.3，在排針的另一側 |
| 顯示區 | 21.7 × 10.9，中心距 PCB 下緣 11.5 | 22.4 × 5.6，中心距排針端 21.5 |
| 安裝孔 | Ø2，間距約 23.3 × 23.6（實測常見值） | 無 |
| 背面零件 | ≤ 1.5 | ≤ 1.2 |

**最重要的是顯示區位置**（決定開窗）。畫面方向若顛倒，用 SSD1306 指令 `0xA0/0xA1`、`0xC0/0xC8` 翻轉。
