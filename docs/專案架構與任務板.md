## 1. 系統架構

```
 1:40 實體模型（fire_model.blend，兩層 × 井字型走廊）
   │  每層 4 台 HUB-8735 Ultra（N/E/S/W 麵包板座，天花板上方設備層）
   │  鏡頭 PS5268，往中心傾斜 18°
   ▼
 HUB-8735 韌體
   ├─ YOLOv7-tiny（NPU，576×320）：火、煙、障礙物……（之後加 6 = person）
   ├─ 人流追蹤計數（people_flow/PeopleFlow.h）
   ├─ 方向指引輸出：OLED（SSD1306，I²C 0x3C，SDA Pin3／SCL Pin4）
   └─ Wi-Fi → 伺服器（POST 偵測結果，回應 leds＝每個路口的方向）
   ▼
 伺服器 fire_evac_v2/app（evac.py：路網、出口、樓梯、最短安全路徑）
   ▼
 RTSP → MediaMTX → WebRTC（看鏡頭畫面）、互動式簡報（對外展示）
```

## 3. 實體模型事實（設計前必對照）

- 唯一正確模型：`實體模型檔案/fire_model.blend`（**不是**建築模型_Demo 的 v12）。**原檔不改**，一律用複本。
- Blender 5.2：`blender -b <複本> --python <腳本> -- <參數>`；參數路徑要英文。1 BU = 1 mm，場景 `Assembly_Full`。
- 每層樓層盒 245×245×108；地板頂 z=8；天花板底約 108、頂約 116–117.6；設備層 117.6–150；層距 150。
- 走廊：1F 環廊中心線 ±99、半寬 18；十字走廊半寬 21；9 個路口在 (i·99, j·99)。樓梯 W(−1,1)、E(1,−1)。
- **1F 地板下方空間與地板圓孔是進煙測試用**；人偶由地板下磁鐵**手動**拖動 → 地板不能裝東西。
- **天花板開孔是排煙孔與排線孔** → 不能拿來裝 OLED，線可以走排線孔。
- 麵包板座 4 座／層在四邊中央（59×97.5×37.5，z 109–146.5），端牆楔形尖端 z≈130.2。
- 比例約 1:40，人偶約 40 mm。
