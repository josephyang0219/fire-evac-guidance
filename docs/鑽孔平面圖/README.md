## 影響

- 中心 C、SE、SW 三塊 OLED 的模組位置與畫面朝向要跟著實際孔改（模組 27.8 × 27.3，排針側＝孔的長邊）；SE 長軸變南北 → 排針側朝東或朝西，畫面上緣方向要重新決定（韌體 OLED_MAP 的 top 參數）。
- 2F 原設計角落孔與 1F 差 0.5–1.8 mm 的部分不再適用（兩層同版型）。
- 待辦：1f-9-oled 依本表重定 C、SE、SW 的模組位置與畫面朝向、更新配置表；之後 hub-node-9 改 OLED_MAP 的 top。
